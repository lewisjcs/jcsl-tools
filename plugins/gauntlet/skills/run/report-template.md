# Gauntlet — the postable comment

The runtime renders the teammate-facing comment: `party-report --party <partyRunId> --format pr-comment` writes `pr-comment.md` beside the party record (run skill, step 8). Nothing in this plugin re-renders, re-words, or re-counts it; the bright line stands — the report file's own vocabulary never appears on a teammate-facing surface, and the rendered comment is the only postable text. `post --party <partyRunId>` publishes it, only at the operator's say-so.
