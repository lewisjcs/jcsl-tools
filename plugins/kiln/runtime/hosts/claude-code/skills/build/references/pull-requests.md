# Pull request rules

The pull request rules hold at a release stop and at `complete`. Check whether each repository of the phase is public: for each name in `show`'s `phase.repos`, take the `root` of its record in `show`'s `repos` (on a run from an older release, the one record) and run `gh repo view "$(git -C <root> remote get-url origin)" --json isPrivate -q .isPrivate`. If any prints `false`, run `pr --ticket <ref> --public`. If every one prints `true`, run `pr --ticket <ref>`. If one prints anything else, stop and say so. Never run `pr` without `--public` on an unknown visibility: on a public repo, that form puts the full text of each finding in the pull request body. One `--public` flag covers every block that the call writes. If `pr` refuses with `KILN_PR_KEY_MISSING`, show its message and stop. `pr` returns `pullRequests`, one entry per repository the phase wrote to, in plan order. For each entry, read `repo`, `worktree`, `branch`, `base`, `titlePath`, and `evidenceBlockPath`. Look for a pull request already on the branch: `gh pr view <branch> --repo "$(git -C <worktree> remote get-url origin)" --json url,state`. When it prints `no pull requests found` and exits non-zero, the branch has none. Push the branch: `git -C <worktree> push -u origin <branch>`. When the lookup's `state` is `OPEN`, an earlier phase opened that pull request and the push updates it: do not open another, and record its `url`. When the branch has none, or its `state` is `MERGED` or `CLOSED`, open a new pull request for that worktree's branch, with no `cd`, always with the entry's base: `gh pr create --repo "$(git -C <worktree> remote get-url origin)" --base <base> --head <branch> --title "$(cat <titlePath>)" --body-file <evidenceBlockPath>`. A run from an older release has no `base`. For that run, leave `--base` out, and the pull request targets the default branch. The branch name and the title follow the repository's own conventions: on the approved-plan route you wrote them before `open`, and on any other route the finder read them at the start of the run. Pass the title through `$(cat <titlePath>)`, not `"<title>"` pasted in. A command substitution's output is not parsed again. The ticket author's raw text (a backtick, a `$(...)`, a `"`) reaches `gh` as one plain argument instead of expanding or breaking the command. The new pull request's URL is the last line it prints. Record each pull request, the open one or the new one: `pr-opened --ticket <ref> --repo <repo> --url <url>`. If push fails, inspect the remote branch before retrying. If pull request creation fails, look for an existing pull request on the same branch before retrying. Keep the person informed of a failure that needs a new decision.
